Local Skill Guide

TISS ISMS 表單預填 Skill 使用說明

將 ClickUp ticket 轉成預填的 ISMS-02-14-01 DOCX。Skill 可放在單一 workspace 中供 Claude、Codex 或 Antigravity 使用，不需安裝 ClickUp CLI 或額外 Python 套件。

Python 3 ClickUp Personal API Token Project-local 更新日期 2026-09-07

使用流程只有四件事

複製完整 Skill 資料夾 → 放到 agent 的專案目錄 → 填寫 .env → 貼上 ClickUp ticket URL 請 agent 產表。

預設輸出檔名 ISMS表單草稿_YYYYMMDD_taskID.docx
01

取得並完整複製 Skill

可使用資料夾或 ZIP。不要只複製 SKILL.md，腳本、範本、人名表與隱藏的 .env 都是必要檔案。

從公司 NAS 下載

請先連線公司 NAS，再從以下路徑取得 Skill 壓縮檔：

/shareall/share/Agent skills/ISMS_系統上線表單預填/tiss-isms-code-update.zip

將 ZIP 複製到自己的 workspace 後解壓縮，應得到 tiss-isms-code-update 同名資料夾。

正確資料夾結構

tiss-isms-code-update/
├── SKILL.md
├── .env
├── assets/
├── references/
└── scripts/
02

放到各 agent 的 local skill 目錄

<workspace-root> 是你用 agent 開啟的專案資料夾。完成後，重新開啟專案或建立新對話，讓 agent 重新偵測 Skill。

Claude Code／Desktop

C

Claude 的 project skill 使用 .claude/skills。

<workspace-root>/.claude/skills/tiss-isms-code-update/
  • SKILL.md 必須位於上述資料夾內。
  • 若本次 session 啟動時還沒有 .claude/skills，新增後重新啟動 Claude。

Codex

X

Codex 的 repository-local skill 使用 .agents/skills。

<workspace-root>/.agents/skills/tiss-isms-code-update/
  • 從 workspace 或其子目錄啟動 Codex。
  • 可直接在 prompt 提及 $tiss-isms-code-update；若未出現，重新啟動 Codex。

Antigravity

A

Antigravity 的 workspace skill 同樣使用 .agents/skills。

<workspace-root>/.agents/skills/tiss-isms-code-update/
  • 將 <workspace-root> 加入 Antigravity Project 的 Folders。
  • 建立新對話；也可用 Skills 畫面確認 Skill 已被載入。
Codex 與 Antigravity 可以共用同一份 local skill。 兩者都讀取 .agents/skills/tiss-isms-code-update/，不必在同一 workspace 內放兩份。Claude 則需另外放在 .claude/skills/。
03

在 Skill 的 .env 填入 ClickUp token

每一份 local skill 都有自己的 .env。開啟該檔案，把範例 token 改成使用者自己的 ClickUp Personal API Token。

.env 內容

CU_API_TOKEN=pk_your_personal_token
CU_TEAM_ID=90181438893

CU_TEAM_ID 已填入本公司 ClickUp Workspace ID，一般不需更改。

憑證處理原則

  • ✓只在自己的 local workspace 副本填入 token。
  • ✓分享 Skill 或重新壓縮前，把 token 改回 placeholder。
  • ✓不要把含真實 token 的 .env 提交到 Git。
  • ✓不要把 token 貼進 prompt、產出文件或聊天訊息。
04

Antigravity 建議設定

這個 Skill 會連續執行讀取 ticket、產生 DOCX、檢查 DOCX 三個 Python 指令。若希望過程不中斷，可讓該 Project 的 terminal commands 自動執行。

設定 Terminal Command 為 Always Proceed

  1. 開啟 Antigravity Settings。
  2. 在左側選取目前的 Project。
  3. 將 Security Preset 設為 Custom。
  4. 將 Terminal Command Auto Execution 設為 Always Proceed。
  5. 目前實測設定為 Sandbox Mode：Disabled。
注意：Always Proceed 代表該 Project 中未被 Deny 的終端機指令可直接執行。只建議用於內容可信、用途單純的專用 workspace；不要對來源不明的專案使用。
05

貼上 ticket URL 請 agent 產表

Claude、Codex 與 Antigravity 都可使用相同的自然語言指令。Skill 會透過 ClickUp API 取得 ticket 的 title、主要描述、Assignees 與 parent task。

建議 prompt

如果 agent 沒有自動選用 Skill，直接寫出 Skill 名稱。

請使用 tiss-isms-code-update skill，根據這張 ClickUp ticket 預填 ISMS 表單：
https://app.clickup.com/t/90181438893/86eynzknt
讀取資料 標題、描述、Assignees、parent task。
必要時詢問 系統名稱不明、人名未對應或可能涉及資料庫增修。
輸出 DOCX 預填表單並自動檢查關鍵欄位與測試日期。
未指定檔名時： 輸出至目前 workspace，命名為 ISMS表單草稿_YYYYMMDD_taskID.docx。例如 ISMS表單草稿_20260907_86eynzknt.docx。
