工作內容

你將為國家運動科學中心的數位平台、資料服務與委外交付建立可重複、可追溯的品質機制。你不只是執行測試，也會從需求階段協助找出缺口，規劃風險導向測試，並以清楚的缺陷證據、回歸結果及上線建議，協助團隊判斷產品是否已達可交付與可驗收狀態。

此職缺以手動測試、API 測試、整合測試與驗收能力為必備，並將依風險與團隊現況逐步建立自動化回歸能力。
  1. 依產品需求、系統風險與委外交付範圍制定 Test Plan、Test Case、Test Data、Traceability Matrix 及 Exit Criteria。
  2. 參與需求／設計評審，提早檢查流程、資料、權限、例外情境與 Acceptance Criteria 是否可測試。
  3. 執行 Web／響應式頁面、後台、API、資料流程及第三方串接的功能、整合、回歸、Smoke、UAT 支援與探索式測試。
  4. 規劃跨瀏覽器、跨裝置、角色／權限、資料正確性、錯誤處理及基本可用性／無障礙檢查。
  5. 建立清楚可重現的缺陷單，包含環境、版本、步驟、預期／實際結果、嚴重度及相關證據，並推動 Triage、修復與驗證。
  6. 管理測試帳號、測試資料、環境需求與版本基線；與工程、廠商及維運角色確認測試環境差異與限制。
  7. 驗證委外廠商交付物是否符合需求、規格與驗收條件，產出測試報告、缺失清單及驗收證據。
  8. 建立 Release Checklist 與品質風險摘要，對上線／暫緩提出具體建議，並追蹤上線後問題。
  9. 依風險與重複性逐步導入 API 或 UI 自動化測試，納入版本回歸流程。
  10. 與 Data Product Manager、專案管理師、設計、前後端、資料、資安／法遵及委外廠商協作改善品質流程。
  11. 視專案需要參與國內場域或展示環境之測試與驗證。

條件要求

必備條件

  1. 大學以上畢業，科系不拘。
  2. 具 2 年以上軟體測試、品質工程、系統驗證或相近經驗。
  3. 具手動測試、Web 測試、API 測試及系統驗收經驗。
  4. 能獨立撰寫 Test Plan、Test Case 與缺陷報告，並依風險安排測試優先序。
  5. 熟悉瀏覽器開發者工具及 Postman、Swagger UI 或同類 API 測試工具。
  6. 了解功能、整合、回歸、Smoke、UAT 與探索式測試的目的及差異。
  7. 能清楚描述問題、整理證據並與內外部開發人員合作追蹤至關閉。
  8. 具良好中文書面表達、邏輯分析能力與細節敏感度。

加分條件

  • 熟悉 Playwright、Cypress、Selenium、Appium、pytest、Newman 或其他自動化測試工具。
  • 具 SQL 或其他資料查詢能力，能核對關鍵資料及資料流程。
  • 具 Git、CI/CD、Docker 或測試環境建置／維護概念。
  • 具資料平台、API 串接、ETL、資料品質或模型輸出驗證經驗。
  • 具委外開發、系統整合、政府採購案測試或正式驗收經驗。
  • 具效能、安全、無障礙或行動裝置測試經驗。
  • 具運動科技、健康科技、個資敏感系統或研究資訊系統經驗。
  • 具 ISTQB 或其他軟體測試相關證照／訓練。

其他條件

  • QA 具獨立品質判斷與上線風險建議責任；最終上線決策依中心核定流程辦理。
  • 需配合低頻國內場域出勤，無長期外派。
  • 工作可能接觸未公開專案資訊、系統權限、研究資料或個人資料，錄取後須遵守中心保密、資安及資料使用規範。
  • 面試時可提供去識別化的 Test Case、Bug Report、Test Summary 或自動化測試作品；若受保密義務限制，可使用自製案例替代。
  • 進用迴避、到職應備文件及福利制度，依國家運動科學中心與本計畫核定規定辦理。
