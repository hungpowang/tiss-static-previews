工作內容

國家運動科學中心正在推動運動科技、運動數據應用與數位平台相關計畫。你將串聯內部團隊、使用單位、合作夥伴與委外廠商，從需求釐清、採購與專案啟動，到履約追蹤、測試驗收及上線維運，建立透明、可追蹤且能落地的交付節奏。

這個職位適合能同時掌握人員協作、時程、風險、文件與交付品質，並願意在制度與實務之間主動解題的人。
  1. 規劃並維護專案範圍、工作分解、里程碑、時程、資源、風險與議題清單。
  2. 統整跨部門需求，協調產品、設計、工程、資料、資安、法遵／研究倫理及行政採購等角色。
  3. 管理委外廠商之工作計畫、交付物、會議、需求變更、缺失改善與履約進度，及早揭露落差並推動解決。
  4. 協助需求規範、採購／招標、評選、議價、簽約、驗收、付款與核銷等相關作業及文件彙整。
  5. 與 Data Product Manager 及 QA 共同建立可驗收的需求、測試範圍、交付證據與完成定義。
  6. 追蹤既有平台的版本、維運、事故、風險、相依服務及合作窗口，維護可追溯的專案文件。
  7. 主持專案會議、整理決策與待辦事項，定期向主管及利害關係人報告進度、風險與需決策事項。
  8. 視專案需要協助國內場域訪談、驗證、展示活動或跨單位協作。
  9. 其他與計畫及專案推動相關之交辦事項。

條件要求

必備條件

  1. 大學以上畢業，科系不拘。
  2. 具 2 年以上專案管理或專案執行經驗，並曾參與軟體、平台、資料或系統整合專案。
  3. 能獨立製作並維護專案計畫、時程、會議紀錄、風險／議題清單與管理報告。
  4. 能將模糊需求拆解為責任人、交付物、完成條件與期限，並主動追蹤至完成。
  5. 具良好的跨部門及廠商溝通能力，能與技術及非技術角色合作。
  6. 具基本數位產品與系統概念，能理解 Web／App、API、資料流程、測試環境、正式環境與版本上線等常用語彙。
  7. 具良好中文書面表達及文件整理能力。

加分條件

  • 曾參與政府計畫、政府採購、法人機構或公部門專案。
  • 具委外開發、系統整合、SaaS、資料平台或資訊服務專案經驗。
  • 熟悉 ClickUp、Jira、Trello、Notion、Confluence 或同類協作工具。
  • 具預算控管、核銷、採購、履約或驗收經驗。
  • 具 PMP、PRINCE2、Scrum 或其他專案管理相關證照／訓練。
  • 對運動科學、運動產業、健康科技、資料治理或公共數位服務有興趣。

其他條件

  • 需配合低頻國內場域出勤，無長期外派。
  • 工作可能接觸未公開專案資訊、系統權限、研究資料或個人資料，錄取後須遵守中心保密、資安及資料使用規範。
  • 面試時可提供去識別化的專案計畫、狀態報告或風險清單；若受保密義務限制，可使用自製案例替代。
  • 進用迴避、到職應備文件及福利制度，依國家運動科學中心與本計畫核定規定辦理。
