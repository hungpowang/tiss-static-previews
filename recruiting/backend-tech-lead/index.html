工作內容

國家運動科學中心正在推動知情平台、運動數據平台與數據中台等運動科技服務。我們希望找到一位仍願意親自開發、同時具備架構與技術帶領能力的資深工程師，成為平台體系的內部技術 Owner。

你將掌握三個系統之間的後端服務、API、資料流、程式碼與應用交付，帶領現有前後端工程師，並與 Data Product Manager、QA、資料工程、SA 及委外廠商合作。

工作約 50% 為核心開發，另 50% 為架構設計、Code Review、技術審查與跨團隊協作。此職位的技術判斷將高度參與並影響平台決策。
  1. 負責知情平台、運動數據平台與數據中台之間的整體技術架構、後端服務及 API 整合。
  2. 親自參與核心後端功能、共用服務、第三方系統串接及既有系統重構。
  3. 擔任現有前端及後端工程師的 Technical Lead，帶領技術設計、任務拆分、Code Review、除錯與交付。
  4. 建立並持續改善程式碼規範、Repository、分支策略、自動化測試及 Release 要求，並與負責 Infra、Kubernetes 與 CI/CD 的 SA 協作完成環境及部署流程。
  5. 盤點既有委外系統的架構、程式碼、API、資料庫、相依服務與技術債，提出接手、改善或重構方案。
  6. 審閱委外廠商的技術方案與交付成果，提出改善建議，協助主管進行技術判斷與驗收。
  7. 協助處理正式環境的重大技術問題、根因分析與改善追蹤；本職缺不要求 24/7 On-call。
  8. 與 Data Product Manager、QA、資料工程、資料科學、UI/UX、資安及委外廠商合作，將產品需求轉化為可維護、可測試的技術方案。
  9. 建立架構、API、應用設定、Release 要求及技術決策文件，降低系統對單一廠商或個人的依賴。
  10. 持續評估平台擴充性、效能、可靠性、安全性及技術債，規劃中長期技術 Roadmap。
  11. 盤點多來源運動數據接入流程中的共通環節與客製差異，推動可重用的 API、資料轉換、驗證、測試與文件化機制，並逐步導入 AI-assisted／Agentic Engineering 提升開發效率。
  12. 視專案需要參與低頻國內運動場域、賽事或展示環境的技術驗證。

條件要求

必備條件

  1. 大學以上畢業，科系不拘。
  2. 具 5 年以上軟體或後端開發經驗，並有帶領 1～3 位工程師或小型技術團隊的實務經驗。
  3. 熟悉 Python 與 FastAPI，具備後端服務、RESTful API、權限及第三方系統串接的設計與開發能力。
  4. 熟悉 Go；或具 Java、C#、Rust、C／C++ 等至少一種編譯型語言的實務經驗，並願意快速上手 Go。
  5. 熟悉關聯式資料庫及資料建模，具 PostgreSQL 或同類資料庫的開發與效能調校經驗。
  6. 具系統架構設計、技術選型、Code Review、測試及既有系統重構經驗。
  7. 熟悉 Git 協作流程，理解 Docker、Kubernetes、CI/CD 與 Linux 環境，能與 SA 協作釐清應用部署、環境與 Release 需求。
  8. 能使用 Log、Metrics 及相關工具進行問題診斷、根因分析與效能改善。
  9. 能帶領其他工程師完成技術設計與交付，並能與產品、QA、資料及非技術角色有效溝通。
  10. 具良好中文技術文件撰寫及溝通能力。

加分條件

  • 具微服務、非同步處理、事件驅動或高流量 API 架構經驗。
  • 具 MongoDB、MinIO／S3-compatible Object Storage、Redis 或訊息佇列使用經驗。
  • 具資料平台、ETL、Apache Iceberg、Spark、DataHub 或大量資料串接經驗。
  • 具 OAuth、OpenID Connect、個資敏感系統、權限管理或 Audit Log 經驗。
  • 具委外系統接手、Legacy System 重構、技術債治理或供應商技術審查經驗。
  • 具 Kubernetes 應用部署、Observability、Incident Response 或可靠性改善經驗。
  • 具 AI-assisted Software Development 或 Agentic Engineering 實務經驗，能將重複但具有領域差異的開發流程拆解為結構化、可重用且可評估的工作流。
  • 曾運用 LLM／Agent 協助 Schema 與欄位理解、OpenAPI／JSON Schema 草稿、API 或 ETL Scaffold、資料品質規則、測試案例、技術文件、視覺化 Prototype 或數據洞察探索。
  • 理解 Human-in-the-loop、結果評估、權限與敏感資料保護，能讓 AI 輔助流程保留必要的人工審查與可追溯性。
  • 具政府計畫、法人機構、運動科技、健康科技或公共數位服務經驗。

聘用與發展

本職缺為計畫型全職人員，首期聘用至 2026 年 12 月 31 日。北部辦公室未來五年之計畫預算已有規劃，工作表現符合期待者，原則上將依年度計畫及考核結果辦理續聘。

中心正逐步建立內部研發 Ownership。此角色將高度參與技術決策，並有機會主導新系統架構、既有平台接手及重構方向。

其他條件

  • 無直接人事管理責任，但需技術帶領現有前後端工程師。
  • Infra、Kubernetes 與 CI/CD 由 SA 主責；本職缺負責應用架構、程式碼與 Release 要求，並與 SA 協作完成環境及部署。
  • 需配合低頻國內場域出勤，無長期外派。
  • 工作可能接觸未公開專案資訊、系統權限、研究資料或個人資料，錄取後須遵守中心保密、資安及資料使用規範。
  • 面試時可提供去識別化的架構設計、程式碼、技術決策或重構案例；若受保密義務限制，可使用自製案例替代。
  • 進用迴避、到職應備文件及福利制度，依國家運動科學中心與本計畫核定規定辦理。
