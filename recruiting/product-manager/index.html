Data Product Manager（運動數據平台）

工作內容

你將負責運動數據平台的產品規劃與持續發展。平台將接收來自大型賽事、地方政府、運動場域、民間場館、穿戴式設備及專業運動器材等多元數據。

你的核心任務，是理解不同運動數據的使用者、應用情境與潛在價值，規劃清楚的產品架構與發展方向，避免平台隨著資料增加而變得零散與雜亂。

你將與資料科學家、UI/UX 設計師及工程團隊密切合作，把運動數據轉化為容易理解的視覺化、數據洞察與產品功能，讓資料不只是被收集，也能真正被使用並產生價值。
  1. 規劃運動數據平台的產品策略、資訊架構、Roadmap 與版本優先序。
  2. 理解不同運動、數據來源、使用者及應用情境，定義適合的產品功能與呈現方式。
  3. 與資料科學家合作，將分析、研究及模型成果轉化為可被使用的數據洞察與產品功能。
  4. 與 UI/UX 設計師合作，規劃平台導覽、資訊層級、數據視覺化及使用流程。
  5. 與資料及軟體工程團隊協作，釐清產品需求、資料邏輯、技術限制與驗收條件。
  6. 撰寫並維護 PRD、User Story、Backlog、流程及 Acceptance Criteria。
  7. 協調內部團隊與委外廠商，推動需求評審、開發、測試、驗收及上線。
  8. 蒐集使用者回饋與產品數據，持續改善平台內容、功能與整體使用體驗。
  9. 視專案需要參與國內運動場域、賽事或展示環境的訪談與驗證。

條件要求

必備條件

  1. 大學以上畢業，科系不拘。
  2. 具 2 年以上數位產品、數據產品、Product Owner、系統分析或相近經驗，曾實際參與 Web、App、SaaS 或資料產品上線／重大改版。
  3. 能清楚說明本人參與之產品成果、問題定義、優先序、取捨、協作方式及上線結果。
  4. 能獨立撰寫 PRD、User Story、流程與 Acceptance Criteria，並管理需求變更。
  5. 具基本技術與資料素養，能與工程團隊討論 API、資料欄位、權限、環境、版本及系統相依性。
  6. 具使用者導向思考、邏輯分析、溝通協調及決策說明能力。
  7. 具良好中文書面表達及簡報能力。

加分條件

  • 具運動科技、健康科技、資料平台、研究資訊系統、B2B／B2G 或公共數位服務經驗。
  • 具 0→1 產品、既有平台重構或多角色後台產品經驗。
  • 熟悉 Figma、FigJam、Miro、ClickUp、Jira、Confluence、Notion 或同類工具。
  • 理解產品分析、漏斗、留存、使用行為或基本 SQL／資料查詢概念。
  • 具 API 串接、資料視覺化、權限管理、同意／授權流程或個資敏感產品經驗。
  • 曾與委外開發或系統整合廠商合作，能把需求轉化為具體可驗收範圍。
  • 對運動科學、運動產業、健康資料或公共服務有熱忱。

其他條件

  • Data Product Manager 負責需求定義、產品優先序與驗收價值；重大範圍、預算及採購決策依中心核定流程辦理。
  • 需配合低頻國內場域出勤，無長期外派。
  • 工作可能接觸未公開專案資訊、系統權限、研究資料或個人資料，錄取後須遵守中心保密、資安及資料使用規範。
  • 面試時請提供可去識別化作品，說明本人實際角色、決策與成果；若受保密義務限制，可使用自製案例替代。
  • 進用迴避、到職應備文件及福利制度，依國家運動科學中心與本計畫核定規定辦理。
